# 角色能力矩阵（当前实现版）

本文档基于当前后端代码实现整理，用于梳理学生、老师、管理员三类角色的能力边界，便于后续需求补充与权限收敛。

## 角色定义

- STUDENT：学生
- TEACHER：老师
- ADMIN：管理员

## 权限判定原则

- 以**后端接口鉴权**为准（`@PreAuthorize` + Spring Security 认证）
- 以**资源归属校验（owner check）**为补充（例如作文归属、文件归属）
- 前端展示/隐藏仅作体验控制，不作为安全边界

## 学生（STUDENT）

### 用户相关

- 可登录：`POST /user/login`
- 可注册：`POST /user/add`（公开注册，后端强制创建为学生角色）
- 可查看本人信息：`GET /user/me`
- 可修改本人信息：`PUT /user/me`
- 可上传本人头像：`POST /user/me/avatar`

### 作文相关

- 可创建草稿：
  - `POST /essay/text`
  - `POST /essay/image`
  - `POST /essay/document`
  - `POST /essay`
- 可修改本人草稿：`PUT /essay/{id}`
- 可提交本人作文：`PUT /essay/{id}/submit`
- 可撤回本人作文：`PUT /essay/{id}/withdraw`
- 可查询本人作文列表：`GET /essay/list`
- 可查看本人作文详情：`GET /essay/{id}`
- 可删除本人草稿：`DELETE /essay/{id}`

### 评审相关

- 可发起本人作文 AI 评审：`POST /review/essay/{id}`
- 可对本人作文发起文本纠错：`POST /review/essay/{essayId}/correct`
- 可查询本人评审记录详情：`GET /review/record/{reviewId}`
- 可查询本人作文评审列表：`GET /review/essay/{essayId}/records`
- 可分页查询本人评审记录：`GET /review/records`
- 可查询评审状态：`GET /review/status/{reviewId}`
- 可删除本人评审记录：`DELETE /review/record/{reviewId}`
- 可读写批改细则：
  - `GET /review/rules`
  - `POST /review/rules`
  - `PUT /review/rules/{id}`
  - `PATCH /review/rules/{id}/status`
  - `DELETE /review/rules/{id}`
- 可只读评分维度：
  - `GET /review/dimensions`

### 文件与 OCR 相关

- 可下载本人文件：`GET /file/download/{fileId}`
- 可获取本人文件临时链接：`GET /file/url/{fileId}`
- 可查询本人作文文件列表：`GET /file/essay/{essayId}`
- 可查询本人 OCR 相关接口：`GET /ocr/**`

## 老师（TEACHER）

老师包含学生的基础能力，并在评审域具备更高权限。

### 额外评审能力

- 可手动批改/修订 AI 结果：`POST /review/teacher/manual`
- 在评审服务层具备评审管理权限，可突破“仅本人作文”的评审归属限制（用于评阅他人作文）
- 可批量发起批改任务（批量提交作文进入评审队列）：`POST /review/essay/batch`
- 可手动修改批改结果（教师人工修订分数/评语）
- 可在 AI 已批改文章上继续批改（基于 `sourceReviewId` 形成教师修订版本）

### 不具备的管理能力

- 无用户管理权限（无 `/user/{id}`、`/user/selectAll`）
- 无评分维度写权限（无 `/review/dimensions` 写接口）
- 无高风险路径直出权限（无 `GET /file/url/path`）

---

## 管理员（ADMIN）

管理员包含老师能力，并具备系统管理权限。

### 用户管理

- 可根据 ID 查询用户：`GET /user/{id}`
- 可根据 ID 修改用户：`PUT /user/{id}`
- 可根据 ID 删除用户：`DELETE /user/{id}`
- 可查询全部用户：`GET /user/selectAll`
- 可创建任意角色用户（管理员接口）：`POST /user/admin/add`
- 可批量导入用户（管理员接口）：`POST /user/admin/import`

### 评审配置管理

- 可新增规则：`POST /review/rules`
- 可更新规则：`PUT /review/rules/{id}`
- 可启停规则：`PATCH /review/rules/{id}/status`
- 可删除规则：`DELETE /review/rules/{id}`
- 可新增维度：`POST /review/dimensions`
- 可更新维度：`PUT /review/dimensions/{id}`
- 可启停维度：`PATCH /review/dimensions/{id}/status`
- 可删除维度：`DELETE /review/dimensions/{id}`

### 高风险文件能力

- 可按任意路径生成临时访问链接：`GET /file/url/path`

---

## 已落地的关键安全策略

- 公开注册接口 `POST /user/add` 已收敛为仅创建学生，避免越权注册教师/管理员
- 管理员创建高权限账号使用专用接口 `POST /user/admin/add`
- 评审和资源访问依赖“角色控制 + 归属校验”双重约束

## 业务决策（已确认）

- 老师允许完整作文创建/修改流程（不仅限于评审相关动作）
- 老师数据范围暂不按班级/课程划分，当前按全局范围处理
- 管理员扩展能力仅保留“批量导入”（`POST /user/admin/import`），不包含“重置密码”和“冻结账号”
